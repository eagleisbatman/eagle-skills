# Eagle Human Writing

Rewrite prose so it sounds human, specific, and less AI-generated.

## Command

```bash
/eagle-human-writing
```

Also triggers on: "make it sound human", "less AI", "no AI voice", "ghost mode", "no corporate tone", "degpt", "write like a journalist", "README polish", and similar rewrite requests.

## What it does

Eagle Human Writing removes recognizable AI writing patterns from prose:

1. Generic openers and filler.
2. Corporate glue phrases.
3. Over-balanced paragraphs.
4. Vague verbs and abstract nouns.
5. Conclusions that only restate the intro.

It replaces them with direct structure, stronger rhythm, concrete details, and a voice that matches the audience.

## Use it for

- README and documentation polish.
- Articles and blog posts.
- Reports, memos, and essays.
- Emails and social posts.
- Any rewrite where the user asks for natural, authentic, or less AI-sounding prose.

## Install note

This skill replaces the standalone `human-writing` skill. Keep the standalone copy installed until `eagle-human-writing` is installed and visible in each target you use.
